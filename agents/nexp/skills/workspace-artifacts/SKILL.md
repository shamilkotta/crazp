# Workspace artifacts

When work produces a file the user should keep (reports, drafts, plans, code snippets):

1. Write under `workspace/` — e.g. `workspace/drafts/`, `workspace/artifacts/`.
2. Use a descriptive filename.
3. In chat, point at the path — do not paste large bodies inline.
